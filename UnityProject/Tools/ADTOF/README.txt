Cross Rhythm ADTOF companion

Cross Rhythm automatically tries to start this local companion on Windows when ADTOF is selected.
If it is not installed yet, run install_adtof.bat once, then start_adtof_server.bat.
The Unity WebGL version can use the same server at http://127.0.0.1:8765.
No song audio is uploaded to TakKa's server; the companion runs on the user's PC.
