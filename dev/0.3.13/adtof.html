ADTOF Setup

音源からドラムのノーツ候補を作ります。Windows版・Unity Web版で使えます。

  1. 初回はPython 3.12をインストールします。
  2. Windows版はEdit → Analyze → Setup / Start。Web版は補助プログラムをDownloadして展開し、Start ADTOF.cmdを実行します。
  3. 初回は必要なソフトとモデルをダウンロードします。起動後、Analyze → Check → ADTOFの順に押します。
  4. 解析が終わったらApplyで反映します。Undoで戻せます。
  • 解析はPC内で実行します。音源をクラウドへ送信しません。
  • Webでローカル接続の許可を求められた場合は、利用するときに許可してください。
  • BPM・開始位置は先に設定します。強弱・種別・ハイハットの開閉は解析後に調整してください。
  • Auto Draftは補助プログラムなしでも使えます。
