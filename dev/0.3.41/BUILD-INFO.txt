# Cross Rhythm 0.3.41 development

## Changes

- コントローラーの短い押下・解放をフレーム間でも保持し、右スティックのスクロール、右スティック押下の右クリック、HomeのTitle復帰を入力経路へ追加しました。PCマウスとコントローラーの仮想カーソルは、最後に操作した側だけを有効にします。
- Songsのホバー効果音を選択中の曲単位で保持し、PCマウスと仮想カーソルが同じ曲を交互に検出して効果音を繰り返す状態を修正しました。
- Windows起動画面の二重起動判定を展開先フォルダー単位へ分離し、別のコピーや別バージョンを同名プロセスだけで再利用しないようにしました。起動画面を先に描画し、復元状況も同じ1画面へ表示してからゲームへ引き継ぎます。
- Windows起動画面の文章を省略せず表示し、右上に文字なしの`×`を配置しました。`×`とEscは同じ起動中止処理を使い、起動中のゲーム本体も終了します。
- Songsのレーン順設定をPreviewと同じ行へ移し、日本語は「スティック側が上 / ペダル側が上」、英語は「Sticks on Top / Pedals on Top」に統一しました。
- EditのGridをノーツ配置の間隔だけに限定しました。通常ノーツは古い長さ情報が残っていても短い打点として扱い、Grid変更や配置で小節をまたぐ長さにならないようにしました。
- 長さを持つノーツをHi-Hat PedalとSnare Buzzに限定し、描画、選択、移動、貼り付け、保存・読込で同じ長さ判定を使うようにしました。通常ノーツでは長さ編集を無効にしています。
