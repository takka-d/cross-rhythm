Cross Rhythm 0.3.34 development

- Config now has Folder, Audio, Timing, Controls and Display categories. Removed its Metronome control; editor metronome remains available.
- Quit pauses the performance behind a confirmation. Resume keeps the score and position; Practice opens paused at the same position; Quit returns to Songs. Keyboard and controller dialog navigation are supported.
- Practice opens the current song in Edit at the current position, independently from the Songs project. Existing editor drafts and history are retained.
- Songs and Practice expose the shared, persistent Hands Above / Feet Above setting.
- Edit has matching start/end transport icons. Undo/Redo buttons and shortcuts show a blocking progress dialog before restoring history.
- Restored every v175 closed hi-hat glyph including strength, outline and MISS. Open hats separate the same original shape into upper/lower halves.
- Triplet guides use a thinner, fainter line than the beat divisions. Practice seek is a slim right-side slider without position text.

Development release only. Production and the WordPress draft were not changed. Native file-dialog gestures and physical controller input are not verified. Browser ZIP completion remains unresolved; the verified ZIP is also provided locally.
