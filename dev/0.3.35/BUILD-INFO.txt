Cross Rhythm 0.3.35 development

- Practice has a compact Volume menu for independent Music and Drums adjustment. It updates the same saved values used by Config and applies while Practice remains open.
- Rebalanced the decoded hi-hat, ride and ride cup output. Strength 3 now measures about 0.030 RMS for each sample path. Ride crash keeps its separately reduced balance.
- The MIDI duplicate-hit review now explains that the choices are source MIDI events, uses full instrument names, and separates source sound, target game sound, track, channel, MIDI velocity and game strength.
- Every MIDI candidate has a Preview button. Import still requires exactly one candidate at each overlapping time and does not alter the chart until confirmation.

Development release only. Production and the WordPress draft were not changed. Native file-dialog gestures, physical controller input and browser ZIP completion remain unverified.
